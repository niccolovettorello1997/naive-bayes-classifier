# Naive Bayes Classifier

A simple implementation of a Naive Bayes classifier in Python using NumPy.

## Overview

This project explores the fundamentals of probabilistic classification and the implementation of a Naive Bayes classifier.

The goal is to understand the underlying mathematics and how NumPy can be used to perform numerical computations efficiently.

## Technologies

- Python
- NumPy

## Getting Started

### Requirements

- Python 3
- NumPy

### Installation

Install NumPy:

```bash
python3 -m pip install numpy
```

### Run the classifier

```bash
python3 naive_bayes.py
```

## Learning Objectives

- Understand the fundamentals of Naive Bayes classification.

- Explore probabilistic predictions.
